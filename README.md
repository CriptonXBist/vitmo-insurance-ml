# Insurance Prediction - vitmo-insurance-ml
Командный проект по предсказанию покупки страховки. Классический ML, CatBoost, FastAPI, Docker.


> Предсказание вероятности покупки страховки на основе табличных данных клиентов.  
> **Метрика:** F1-score для класса `1` (купил страховку)  
> **Дедлайн защиты:** конец декабря 2026
