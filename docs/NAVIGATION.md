# Навигация по репозиторию

Этот документ описывает структуру проекта, назначение каждой папки и файла, а также правила работы с ними.  
Структура будет расширяться по мере развития проекта — сюда будут добавляться новые разделы.

---

## 📂 Корень репозитория

| Файл | Назначение |
|------|-----------|
| `README.md` | Главный файл проекта: описание задачи, состав команды, метрики, этапы выполнения, стек технологий. |
| `LICENSE` | Лицензия проекта (MIT). |

## `Notebooks/` — Jupyter-блокноты команды

Здесь лежат все исследовательские и экспериментальные ноутбуки.  
**Правило:** один ноутбук — один автор. Перед коммитом — `Kernel → Restart & Run All` и `Clear All Outputs`.

| Файл | Содержание |
|------|-----------|
| `01_eda.ipynb`  Разведочный анализ данных: типы признаков, пропуски, баланс классов, корреляционная матрица. |
| `02_feature_engineering.ipynb`  Feature Engineering: Target Encoding, агрегации, взаимодействия признаков, кодирование категорий. |
| `03_modeling.ipynb`  Обучение моделей, кросс-валидация, подбор гиперпараметров, анализ ошибок. |
| `04_experiments.ipynb`  Расширенные эксперименты: Optuna, сравнение моделей, анализ важности признаков. |
| `05_ui_prototype.ipynb`  Прототип пользовательского интерфейса (Streamlit / Gradio). |
| `VITMO_Team.ipynb`  **Общий рабочий ноутбук** со всеми текущими наработками. Впоследствии будет разбит на модульные файлы в `src/`. |
| `.gitkeep`  Пустой файл для отслеживания папки в Git. |

## `data/` — Датасеты

⚠️ **Файлы из этой папки НЕ коммитятся в Git** (они в `.gitignore`).  
Для получения данных следуйте инструкции в `DATA_SETUP.md`.

| Путь | Назначение |
|------|-----------|
| `data/raw/` | Исходный датасет от преподавателя (CSV с Яндекс.Диска). |
| `data/processed/` | Обработанные финальные датасеты в формате Parquet: `train_final.parquet`, `test_final.parquet`. |
| `data/DATA_SETUP.md` | Инструкция по скачиванию и подготовке данных для новых участников команды. |
| `data/.gitkeep` | Пустой файл для отслеживания структуры папок в Git. |

## 🐍 `src/` — Переиспользуемый Python-код

Здесь лежит вся логика, которую используют ноутбуки и будущие сервисы (API, UI).  
**Правило:** если функция появилась в ноутбуке и нужна больше одного раза — она переносится сюда.

| Файл | Назначение |
|------|-----------|
| `__init__.py` | Делает `src` Python-пакетом (позволяет `from src.features import ...`). |
| `config.py` | Единая точка конфигурации: пути к данным, константы проекта (`HOLD_OUT_SIZE=1_000_000`, `TARGET_COL='Response'`, `N_FOLDS=5`, `RANDOM_SEED=42`). |
| `preprocessing.py` | Загрузка данных, `safe_downcast`, безопасный сплит на train/test (последние 1M строк → hold-out). |
| `features.py` | Feature Engineering: Target Encoding с Bayesian smoothing, агрегации, взаимодействия признаков, кодирование категорий, группировка редких классов. |
| `metrics.py` | Расчёт целевой метрики (`f1_score` для класса 1), поиск оптимального порога классификации. |
| `modeling.py` | Обучение моделей, кросс-валидация (`StratifiedKFold`), подбор гиперпараметров. |
